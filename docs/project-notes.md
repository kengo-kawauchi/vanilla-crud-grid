## 画面仕様

### 実装する要素

- 画面タイトル
  - 左上に表示

- 戻る
  - 一部画面のみで表示
  - 画面上部に表示
- 閉じる
  - 一部画面のみで表示
  - 画面上部に表示

- 検索
  - 画面上部に表示
  - 主要項目に絞った固定フォーム検索
- データ件数の表示カウンター
  - 画面にあるデータ件数を表示
  - 上限超過時は 表示上限件数/総件数 を表示

- 主操作
  - 新規登録
    - 画面上部に表示
    - テーブル先頭に1行追加する
  - 保存
    - 画面上部に表示
    - 1行ごとに保存せず一括保存
    - 複数同時に「新規登録・編集・削除」可能
    - エラーもしくは競合が1件でもあったら全件ロールバック
  - 未保存の変更件数
    - 未保存となっている「新規登録、編集、削除」の合計件数を表示
    - 0件の場合は表示しない
- 補助操作
  - ダウンロード
    - 一部画面のみで表示
    - 画面上部に表示
    - Excel形式でダウンロードされる
    - 左端に削除フラグ列を追加したテーブルの内容が出力される
  - アップロード
    - 一部画面のみで表示
    - 画面上部に表示
    - 全件洗替ではなく差分更新
    - 削除フラグが立っているレコードのみが削除される
    - 楽観的排他制御を実施するためにテーブルにversion列を持たせる(画面には表示しない)
    - エラーもしくは競合が1件でもあったら全件ロールバック
    - エラー内容はシンプルなcsvファイル [行番号, 列名, エラー内容] を自動ダウンロードさせる

- メッセージボックス
  - 画面上部に表示
  - メッセージ件数も表示
  - 折りたたみ可能
  - 高さ固定ではみ出る分はスクロール
  - メッセージがあるときのみ表示
  - メッセージ種別
    - INFO
      - 何かの処理が成功したときの情報(グリーン)
    - WARN
      - 注意が必要な内容の説明(イエロー)
    - ERROR
      - 何かの処理で異常が発生したときの通知(レッド)

- テーブル
  - ヘッダは固定
  - 表示件数の上限を設定(例: 1,000件まで)
    - 「検索結果が1,000件を超えています（総件数：3,500件）。条件をさらに絞り込んでください」と正確な総ヒット数を伝え、1,000件以降を表示しない理由を明示する。
- セル
  - エラーセルは赤ハイライト
  - エラー内容自体は各セルには表示しない
- 編集
  - 各行の左端に固定表示
  - クリックすると「中止」ボタンに変化する
- 削除
  - 各行の左端に固定表示
  - 既存データで削除をクリックすると「戻す」ボタンに変化して、行全体はグレーアウトして残る
  - 新規追加データは削除をクリックで行自体を画面から削除する

- ローディングインジケーター（スピナー）
  - 「処理中」であることを示すアニメーション
  - 画面全体をマスク
  - 対象処理: 検索,保存,アップロード,ダウンロード

- 未保存チェック
  - 未保存の変更がある場合に次の対象処理を実行するとアラートを表示
  - 対象処理: 戻る,閉じる,検索,アップロード

### 画面上部の固定表示

- 検索からテーブルヘッダまでを固定
- タイトルは固定しない

### 実装を検討中の要素

- ブラウザの戻るボタン
  - 確認ダイアログを表示
- ブラウザの閉じるボタン
  - 確認ダイアログを表示

```txt
| コード [_____] 名称 [________] [検索]                        表示件数: 128件  ←ここから固定
+-----------------------------------------------------------------------------+
| [新規登録] [保存] 未保存の変更:3件                                 [DL] [UP]
+-----------------------------------------------------------------------------+
| メッセージ  2件  ▼ ← 折りたたみ可能
| ----------------------------------------------------------------------------
| ・行5 : 同時更新エラーが発生しました。再検索し最新データを取得してください。
| ・行12: コードが重複しています
+-----------------------------------------------------------------------------+
| +-----------------------------------------------------+
| |    操作     | コード | 名称     | 状態 | 更新日時   | ← ここまで固定
| +-----------------------------------------------------+
| | 編集 | 削除 | A001   | 商品AAAA | 有効 | 2026/10/01 |
| | 中止 | 削除 | A002   | 商品BBBB | 有効 | 2026/10/02 | ← 編集中の行
| | 編集 | 削除 | A003   | 商品CCCC | 無効 | 2026/10/03 |
| | 編集 | 戻す | A004   | 商品DDDD | 有効 | 2026/10/04 | ← 削除予定の行(行全体グレーアウト)
| | 編集 | 削除 |        |          |      |            | ← 新規追加行
| +-----------------------------------------------------+
+-----------------------------------------------------------------------------+
```

## デザイン

### カラーシステム

- 配色の比率の目安（60:30:10 または 70:25:5）
  - ベースカラー（土台・背景）：約60%〜70%（白、黒、グレーなど）
  - メインカラー / プライマリー（主役）：約25%〜30%（ブランドの顔となる色）
  - アクセントカラー（差し色）：約5%〜10%（一番目立たせたい部分

  - ベース
  - プライマリー
  - セカンダリー
  - アクセント

- セマンティック
  - サクセス
  - エラー
  - 警告
  - 情報

ベース（70%）
メイン + セカンダリー（25%）
アクセント（5%）

### 表

- 列幅
  - 最大値、最小値を決めてその範囲内で自動調整させる
  - 列幅を超過するテキスト
    1. 基本(デフォルト)
       - 折り返し表示
       -「氏名」「カテゴリ」「ステータス」などは、折り返してでもすべて見せる。
    2. 特定の列のみ
       - 省略＋ツールチップ
       -「詳細説明」「備考」のようなフリーテキスト欄だけを指定して text-overflow: ellipsis; を適用する。
       - 文字数が予測不可能で、最悪の場合100文字以上になる可能性がある場合に使用する。
